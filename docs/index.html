The shape

Almost everything is gate-hard here — that's the point.

Every domain decides its own gate-hard/debate-argued split by how deterministically checkable a risk actually is. For unclaimed money, "is this real" is about as checkable as it gets: either an official government or settlement-administrator domain hosts the claim, or it doesn't. That leaves very little for the debate to argue — mostly whether the paperwork is worth the confirmed payout, and watching for the one real scam pattern in this space: fee-charging "recovery services" that attach themselves to a real, free claim.

Live-validated

5 real, currently-open FTC refund programs, ~$0.11 spent.

The Settlement-Claims Scout found five real, currently-open FTC refund programs and correctly cited only the official ftc.gov page for each — so all five verified, legitimately, not from miscalibration. The full pipeline ran end to end on real data: the Ranker scored payout size and certainty, the debate's Skeptic correctly flagged Zelle-payout phishing risk as the actual residual concern for this domain (a real, well-documented fraud pattern), the deterministic mission picked the top 3 within budget, and the digest rendered cleanly.

Known scam pattern this org watches for: official unclaimed-property and settlement claims are always free to file directly. Fee-charging "recovery service" middlemen are the Scam Detection Agent's primary target — any source that isn't the registry itself fails the gate outright.
